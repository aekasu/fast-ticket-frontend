## Starting a session

This is a separate project from the backend at `../fast-ticket`; its `CLAUDE.md` workflow does not apply here.
At the start: read `AGENTS.md` (above), check `git log --oneline -10` and `git status`, and read the backend's
`notes/CLIENTS.md` and `notes/EVENTS.md` before touching anything that calls the API. Tell the user in a few lines
what state the project is in, and ask about any "Open decision" that blocks the next step.
